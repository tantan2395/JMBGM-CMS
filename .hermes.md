## 2. Branch Protection & Git Targets
- **LOCKED PRODUCTION BRANCH:** Never push directly to `main` / `master` (triggers Netlify production builds).
- **WORKTREE ISOLATION:** Always spawn isolated worktrees under `.worktrees/<branch-name>`:
  `git worktree add .worktrees/<branch-name> -b <branch-name>`
- **NAMING CONVENTION:** `feat/<track>-<slug>` or `fix/<track>-<slug>`.

## 3. Tech Stack & Architectural Boundaries
- **Stack:** Next.js 16, Payload CMS 3, Tailwind CSS 4, Supabase PostgreSQL, deployed on Netlify.
- **Schema & CMS Safety:** Never run destructive database migrations or overwrite Payload CMS collection schemas/types without an explicit directive from the Strategic Brain.

## 4. Verification & Artifact Hygiene
- **Verification:** Run typecheck and build verification inside the worktree prior to reporting back.
- **Cleanup:** Delete `.next/` build caches and unlink symlinked `node_modules` inside the worktree before executing `git worktree remove`.
